AI-Based Mosquito Breeding Site Detection System
1. Project Overview
The AI-Based Mosquito Breeding Site Detection System is a machine-learning and geospatial application designed to identify potential mosquito breeding habitats using satellite imagery and environmental data.

The system will analyse environmental features, identify potential water bodies and other suitable habitats, and generate geographical risk classifications to support mosquito surveillance and malaria prevention activities.

4. Project Directory Structure
data/ – Stores raw, processed and labelled datasets.
notebooks/ – Contains experiments and data analysis.
src/ – Contains the main application source code.
configs/ – Stores configuration files.
tests/ – Contains software tests.
docs/ – Contains project documentation.
5. Important Scientific Limitation
Satellite imagery identifies potential mosquito breeding habitats; it does not directly confirm the presence of mosquito larvae. Field observations are therefore necessary to validate detected sites.
